# Zarkhez Voice Studio Recording Script & Swap-In Checklist

Replace any cloud pre-generated clip with authentic human recordings from real Pakistani Urdu and Sindhi agricultural advisors.

## 1. Equipment & Environment Checklist
- Quiet indoor room with curtains/carpet to prevent echo (zero fan, AC, traffic, or tractor background noise).
- Cardioid condenser/USB mic or clean phone voice recorder 15–20 cm from mouth with a pop filter.
- Record at **48 kHz, 16-bit PCM WAV** (mono) and export final web-ready clips as **MP3 64–96 kbps mono** or WAV.
- Maintain steady, calm, warm, mature rural-friendly pacing (~125–135 words/min — not news anchor rush).
- Normalize peaks around **-3 dBFS** and trim silence to ~150 ms head / ~250 ms tail.

## 2. Folder Drop-In Convention (Zero Code Changes Needed)
Place native recorded files here — `VoiceService` automatically checks this directory BEFORE calling any cloud TTS provider:

```
public/audio/native/{lang}/{gender}/{clip_id}.mp3
```
Example:
- `public/audio/native/ur/female/greet_welcome.mp3`
- `public/audio/native/ur/male/alert_spray_unsafe.mp3`
- `public/audio/native/sd/female/greet_welcome.mp3`
- `public/audio/native/sd/male/advice_wheat_first_water.mp3`

(And matching hashed cache keys generated by `npx tsx scripts/pregenerate-voice-clips.ts` populate `public/audio/cache/`.)

## 3. Native Recording Prompt Sign-Off Checklist
- [ ] All 60+ static Urdu strings recorded cleanly in both Female (mature calm mentor) and Male voices.
- [ ] All 60+ static Sindhi strings approved in `data/voice/sindhi-review.csv` (`approved=true`) BEFORE studio recording.
- [ ] Check Sindhi aspirated/implosive consonants carefully: `ڀ ٻ ڄ ڃ ڇ ڏ ڊ ڌ ڍ ڙ ڦ ڪ ڳ ڱ ڻ ٿ ٺ ٽ`.
- [ ] Verify numbers (`27°C`, `06:39`, `17:41`, `41%`, `3.1 m/s`) read in natural conversational style without unnatural English insertions.
- [ ] Test every clip inside `/ur/voice-test` with 5 native farmers/speakers (target >= 4.0 / 5.0 across Clarity, Naturalness, Accent, Number Correctness).
